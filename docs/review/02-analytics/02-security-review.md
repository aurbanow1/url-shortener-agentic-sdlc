## Salt evidence boundaries

The disposal claim covers the bean's retained salt array and day field. `SecretKeySpec` deliberately copies a key so an already selected request can finish after midnight. Such transient key/crypto objects are ordinary JVM memory, not a promise of secure erasure of every heap copy. Process-memory compromise is an accepted threat-model boundary. The expiry test uses a controlled clock and a real scheduler; no natural UTC midnight was crossed or hard real-time scheduling guarantee measured. A wall clock stepping backwards across midnight may draw a fresh earlier-day salt, as already documented in ADR-0012.

Code CR-01 is the timing setup of the separate midnight regression test; it does not negate the independently observed quiet-day and close disposal. QA should consume this explicit item-12 row when judging the salt evidence, while retaining the overall candidate's failed code-review status.
